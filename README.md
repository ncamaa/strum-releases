# Strum downloads

Strum is a free, local Mac app that turns a YouTube link into a playable chord sheet: chords over the lyrics, transpose and capo, auto-scroll and playback that follows the recording. The listening happens on your own machine.

Website: https://strumchords.org

Download the latest DMG from the Releases page.

Requirements: a Mac with Apple silicon (macOS). Builds are signed and notarized, so the app opens like any other Mac app.
